Политика конфиденциальности Tulpar Memory

Обновлено: 17 ноября 2026.

Кто пользуется

Tulpar Memory — личный сервис одного владельца. Других пользователей у него нет.

Какие данные и зачем

Сервис получает доступ drive.file к Google Диску владельца и использует его только для того, чтобы складывать файлы владельца в папку «Tulpar Память» и читать их оттуда. Файлы, которые сервис не создавал, ему недоступны.

Передача третьим лицам

Данные никому не передаются и не продаются, не используются для рекламы и для обучения моделей. Папка не открывается для общего доступа.

Хранение и удаление

Файлы хранятся в Google Диске владельца, пока он сам их не удалит. Ключи доступа хранятся только на сервере владельца.

Как отозвать доступ

myaccount.google.com → Безопасность → Сторонние приложения и сервисы → Tulpar Memory → Удалить доступ. Файлы в Диске при этом не удаляются.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English)

Tulpar Memory is a personal service with a single owner. It uses the drive.file scope only to store the owner's files in a dedicated folder of the owner's own Google Drive and read them back. Data is never shared with or sold to third parties, never used for advertising or model training, and the folder is never shared. Files stay in the owner's Drive until the owner deletes them. Access can be revoked at myaccount.google.com → Security → Third-party apps & services. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
