Tulpar Memory

Tulpar Memory — личный сервис для одного владельца. Он сохраняет файлы владельца (вложения из его рабочего чата) в его собственный Google Диск, в отдельную папку «Tulpar Память».

Приложение запрашивает только доступ drive.file: видит и меняет лишь файлы, которые создало само. Остальное содержимое Диска ему недоступно. Папка приватная, приложение её никому не открывает.

Tulpar Memory is a personal, single-owner service. It stores the owner's files (attachments from the owner's work chat) in the owner's own Google Drive, in a dedicated folder. It requests only the drive.file scope, so it can access only files it created itself; the rest of the Drive is not accessible. The folder is private and is never shared.
